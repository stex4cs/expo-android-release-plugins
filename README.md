# expo-android-release-plugins

Four Expo config plugins for building Android releases locally with Gradle, without EAS.

In a managed Expo project `android/` is generated by `expo prebuild`. Anything you change there by hand is quietly overwritten the next time prebuild runs, and the damage usually shows up one build later: a bundle signed with the debug key, a `versionCode` three bumps behind, a release crash from a class R8 renamed. These plugins move each of those edits into `app.json`, so they survive every prebuild.

They come from the release setup of [Correct Score Pro](https://popzify.com/ui), a React Native app for iOS and Android. Each file starts with a comment explaining what broke without it.

## The plugins

| Plugin | What it does |
| --- | --- |
| `withReleaseSigning` | Signs release builds with your upload key, read from `credentials/keystore.properties` (outside `android/`, so prebuild can't delete it). Without the key an APK still builds, debug-signed, for testing; a Play bundle (`bundleRelease`) stops with a clear error instead of producing an AAB Play would reject. |
| `withVersionFromAppJson` | Makes `build.gradle` read `versionCode` and `versionName` from `app.json` at build time instead of keeping the number prebuild wrote last time. |
| `withAndroidAbi` | Ships `armeabi-v7a` and `arm64-v8a` only (x86 is emulators and Chromebooks), and turns on R8 minification, resource shrinking and optimized resource shrinking. `EXPO_ANDROID_ARCHS=arm64-v8a` for a faster local build. |
| `withProguardRules` | Keep rules for React Native, Hermes, Expo modules and common libraries that find classes by reflection or JNI, plus `-repackageclasses`. Edit the list to match your dependencies. |

## Use

Copy `plugins/` into your Expo project and register them in `app.json`:

```json
{
  "expo": {
    "plugins": [
      "./plugins/withAndroidAbi",
      "./plugins/withProguardRules",
      "./plugins/withVersionFromAppJson",
      "./plugins/withReleaseSigning"
    ]
  }
}
```

For signing, put the keystore and a properties file next to `android/`:

```
credentials/
  upload.keystore
  keystore.properties
```

```properties
storeFile=../credentials/upload.keystore
storePassword=…
keyAlias=upload
keyPassword=…
```

`storeFile` is relative to `android/`. Keep `credentials/` out of git and back it up somewhere private: lose the upload key and you can't update the app.

Then:

```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease   # APK
cd android && ./gradlew bundleRelease     # AAB for Play
```

## Requirements

Expo SDK 50 or newer (uses `expo/config-plugins`). `android.r8.optimizedResourceShrinking` needs Android Gradle Plugin 8.7+; older versions ignore it.
